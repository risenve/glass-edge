# Края в фокусе

Веб-инструмент: чёткий центр, «стеклянное» размытие по краям — как взгляд через очки или сквозь линзу.

## Два варианта (переключатель «Вариант → эффект»)
- **Фигура-стекло над фото** — фото видно целиком, сверху лежит фигура-«окно» со стеклянным преломлением (liquid glass). Фигура по умолчанию — скруглённый сквиркл; можно выбрать круг/овал/прямоугольник или загрузить свой SVG.
- **Стекло по краям фото** — чёткий центр, стекло нарастает к краям кадра (зона: эллипс/круг/прямоугольник).

## Что умеет
1. **Загрузка фото** — кнопка, drag&drop или вставка из буфера.
2. **Кроп** — формат (оригинал / 1:1 / 4:5 / 3:4 / 9:16 / 16:9 / 3:2), зум, сдвиг по X/Y (или просто тащить фото мышью).
3. **Эффект краёв** — центр остаётся резким, к краям нарастает размытие:
   - форма чёткой зоны: эллипс / круг / прямоугольник;
   - размер чёткого центра, плавность перехода, сила размытия;
   - лупа центра (лёгкое увеличение, как линза);
   - блик-стекло по кромке зоны;
   - затемнение краёв.
4. **Экспорт** — PNG / JPG / WebP, качество, размеры.

Один статичный `index.html`, без зависимостей. Хостится на GitHub Pages.
